PROTOTIPO FUNCIONAL — GESTIÓN ACADÉMICA
Proyecto Integrador

CONTENIDO IMPLEMENTADO
1. Pantalla de Bienvenida.
2. Pantalla de Inicio con menú.
3. Primera opción del menú: Horario académico.
4. Captura funcional de una nueva clase mediante el botón +.
5. Selección de día de la semana.
6. Guardado local de clases en el navegador.
7. Eliminación de clases registradas.

CÓMO ABRIRLO
- En Windows: doble clic en index.html.
- También puede abrirse desde un teléfono copiando la carpeta y abriendo index.html en un navegador compatible.
- Para una demostración más estable en PC, puede ejecutar un servidor local:
  python -m http.server 8000
  Luego abrir http://localhost:8000

FLUJO PARA PRESENTAR EN CLASE
1. Abrir index.html.
2. Mostrar la Pantalla de Bienvenida.
3. Pulsar “Entrar al prototipo”.
4. Seleccionar “Horario”.
5. Pulsar el botón +.
6. Registrar asignatura, día, horas y aula.
7. Pulsar “Guardar clase”.
8. Comprobar que la clase aparece en el horario y persiste si se recarga la página.

Este prototipo se basa en las funciones definidas para la aplicación de gestión académica: horarios, tareas, evaluaciones, recordatorios y organización estudiantil.
